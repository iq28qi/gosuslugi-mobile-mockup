МОБИЛЬНЫЙ МАКЕТ · ОБНОВЛЕНИЕ 10.10.2026

Готовый сайт: https://iq28qi.github.io/gosuslugi-mobile-mockup/
Исходники: https://github.com/iq28qi/gosuslugi-mobile-mockup

Экраны: заставка, ввод кода, главная, профиль, уведомления, услуги, документы,
платежи и история, каталог приложений, робот Макс, паспорт и его реквизиты.
Дата рождения на всех экранах и при копировании: 02.10.2008.

Для входа нажмите любые четыре цифры. Нижнее меню переключает разделы.
Имя открывает профиль, колокольчик — уведомления, «Другие» — каталог.
В деталях паспорта можно выбрать изображения или PDF с устройства.
Файлы остаются только в текущей вкладке и не загружаются на сервер.
Чат Макса — локальная демонстрация, GPT не подключён.

Макет не является официальным сервисом или документом.
Вводимые цифры и сообщения не передаются. Реальные платежи и заявления
не выполняются. Анимации учитывают настройку уменьшения движения.

ФАЙЛЫ АРХИВА
index.html — готовый сайт, включая стили, JavaScript и изображения.
icon-180.png, icon-512.png, icon.svg — иконки.
manifest.webmanifest — параметры веб-приложения.
serve.cjs — локальный HTTP-сервер (требуется Node.js).

ЛОКАЛЬНЫЙ ЗАПУСК
Откройте index.html или выполните node serve.cjs в папке проекта.
Локальный адрес: http://localhost:5173/.
Для телефона используйте опубликованный адрес сайта.

ИСХОДНИКИ
В репозитории build_index.js собирает index.html из screens.html,
mobile-ui.css, mobile-app.js, status-bar.html, extracted_images.json
и reference-assets.json. После редактирования выполните node build_index.js.

НА ГЛАВНЫЙ ЭКРАН IPHONE
В Safari откройте сайт → Поделиться → На экран «Домой» → Добавить.
На Android соответствующая команда находится в меню браузера.
