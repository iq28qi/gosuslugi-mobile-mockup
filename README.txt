ПОЛНЫЙ КОД МОБИЛЬНОГО МАКЕТА

Обновление от 10.10.2026: интерфейс по приложенным скриншотам, дата рождения 02.10.2008 на карточке, в деталях, профиле и при копировании. Плавные переходы, реакция кнопок на нажатие, горизонтальная прокрутка карточек, выезжающие панели. Системная настройка уменьшения движения отключает анимации.

index.html — весь HTML, CSS, JavaScript и встроенные изображения.
icon-180.png — иконка для главного экрана iPhone.
icon-512.png — большая иконка.
icon.svg — редактируемый исходник иконки.
manifest.webmanifest — настройки открытия как веб-приложения.

Никакие установки или сборка не нужны. Экран кода пропускает после любых четырех нажатий; цифры не сохраняются и не передаются. Данные в карточке вымышленные. Это макет, не официальный сервис.

ЛОКАЛЬНЫЙ ЗАПУСК
На компьютере откройте index.html в браузере. Если установлен Node.js, команда node serve.cjs в папке проекта запускает http://localhost:5173/. Этот адрес доступен на компьютере, где запущен сервер. Для открытия на телефоне разместите файлы архива site-mobile.zip на своем хостинге и откройте его адрес в мобильном браузере.

В рабочей папке build_index.js генерирует index.html из исходника и extracted_images.json. Команда node build_index.js обновляет готовый HTML. verify-mobile.cjs проверяет переходы и размеры экрана через установленный в среде Playwright/Edge; проверка требует работающего локального сервера.

БЕСПЛАТНОЕ РАЗМЕЩЕНИЕ ЧЕРЕЗ GITHUB PAGES
1. Зарегистрируйтесь на https://github.com/ в Safari.
2. Создайте публичный репозиторий, например mobile-prototype. Добавьте README при создании, чтобы появилась ветка main.
3. В репозитории откройте Add file → Upload files. Загрузите index.html, icon-180.png, icon-512.png и manifest.webmanifest из распакованного архива, затем Commit changes.
4. Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save.
5. Подождите публикации. Ссылка появится в Settings → Pages.
На узком экране включите «Версия для компьютера» в Safari. Код и сайт публичные. Бесплатность и доступность зависят от правил сервиса, вечное размещение никто не гарантирует.

АЛЬТЕРНАТИВА: NETLIFY DROP
Войдите в бесплатный аккаунт https://app.netlify.com/ и откройте https://app.netlify.com/drop. Загрузите ZIP/папку сайта в область публикации. Мобильная доступность выбора файла зависит от текущего интерфейса сервиса. Для обновления используйте тот же проект. У бесплатного плана есть лимиты использования.

ИКОНКА НА IPHONE
Откройте опубликованный сайт в Safari → Поделиться → На экран «Домой» → назовите «Макет» → Добавить. Если есть «Открывать как веб-приложение», включите. Если пункта нет, в меню «Поделиться» нажмите «Изменить действия» и добавьте его. Иконка уже включена в проект. Чтобы поменять ее, замените icon-180.png своей квадратной PNG, а затем удалите старый ярлык и добавьте заново.
