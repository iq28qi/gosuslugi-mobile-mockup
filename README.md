# Мобильный макет

Интерактивный мобильный сайт по предоставленным скриншотам. Включает заставку, ввод кода, главную, профиль, уведомления, каталог приложений, услуги, документы, платежи и чат с роботом Максом. Карточка паспорта дополнена отдельным экраном реквизитов и выбором локальных изображений/PDF. Дата рождения в макете — **02.10.2008**.

## Открыть сайт

[Мобильный макет](https://iq28qi.github.io/gosuslugi-mobile-mockup/)

На экране ввода кода нажмите любые четыре цифры. Нижнее меню переключает основные разделы. Имя открывает профиль, колокольчик — уведомления, «Другие» — каталог приложений. «Паспорт» открывает карточку, «детали документа» — реквизиты. Работают переходы назад, поиск, фильтры и отметка уведомлений, переключение истории платежей, копирование и демонстрационный чат.

Интерфейс учитывает узкие экраны, поворот телефона, безопасные области iPhone и изменение высоты при появлении клавиатуры. На компьютере показана рамка телефона; на мобильном устройстве используются системные строки состояния. Анимации учитывают настройку уменьшения движения.

Это демонстрационный макет, не официальный сервис и не документ. Цифры кода и сообщения не передаются на сервер. Выбранные файлы доступны только локально в текущей вкладке и исчезают после перезагрузки. Государственные системы, реальные платежи и GPT не подключены.

## Файлы

- `index.html` — готовый сайт с HTML, CSS, JavaScript и встроенными изображениями.
- `icon-180.png`, `icon-512.png`, `icon.svg` — иконки и исходник.
- `manifest.webmanifest` — параметры установки на главный экран.
- `build_index.js` — генератор готового HTML.
- `screens.html`, `mobile-ui.css`, `mobile-app.js`, `status-bar.html` — дополнительные экраны, адаптивные стили, поведение и строка состояния для предпросмотра.
- `extracted_images.json`, `reference-assets.json` — встроенные изображения из предоставленных пользователем материалов.
- `serve.cjs` — локальный HTTP-сервер без дополнительных зависимостей.

## Локальный запуск

Откройте `index.html` в браузере или выполните команду при установленном Node.js:

```sh
node serve.cjs
```

Адрес локального сервера — `http://localhost:5173/`.

После изменения исходника обновите HTML:

```sh
node build_index.js
```

Сборка для GitHub Pages не требуется: сайт публикуется из корня ветки `main`.

Для Vercel готовый сайт также находится в корне: Root Directory `./`, Framework Preset `Other`, без команды сборки и с Output Directory `.`. Переменные окружения не требуются.
