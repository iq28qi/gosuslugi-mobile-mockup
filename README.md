# Мобильный макет

Интерактивный мобильный сайт по предоставленным скриншотам: заставка, экран ввода кода, главная страница и карточка паспорта. Дата рождения в макете — **02.10.2008**.

## Открыть сайт

[Мобильный макет](https://iq28qi.github.io/gosuslugi-mobile-mockup/)

На экране ввода кода нажмите любые четыре цифры. Кнопка «Паспорт» открывает карточку. Детали, поиск, уведомления и кнопки главного экрана открывают панели. Анимации учитывают системную настройку уменьшения движения.

Это демонстрационный макет, не официальный сервис и не документ. Вводимые цифры не сохраняются и не передаются. Государственные системы и реальные платежи не подключены.

## Файлы

- `index.html` — готовый сайт с HTML, CSS, JavaScript и встроенными изображениями.
- `icon-180.png`, `icon-512.png`, `icon.svg` — иконки и исходник.
- `manifest.webmanifest` — параметры установки на главный экран.
- `build_index.js`, `extracted_images.json` — исходник и изображения для генерации готового HTML.
- `serve.cjs` — локальный HTTP-сервер без дополнительных зависимостей.

## Локальный запуск

Откройте `index.html` в браузере или выполните команду при установленном Node.js:

```sh
node serve.cjs
```

Адрес локального сервера — `http://localhost:5173/`.

После изменения исходника обновите HTML:

```sh
node build_index.js
```

Сборка для GitHub Pages не требуется: сайт публикуется из корня ветки `main`.
